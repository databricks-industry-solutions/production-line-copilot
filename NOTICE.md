Synthetic data provenance
------------------------------------------------------------------------------
All datasets shipped with, or generated by, this project — including brewery
packaging-line telemetry, OEE/line KPIs, machine state, event logs, quality
checks, inventory snapshots, maintenance windows, crew/production schedules,
and incident scenarios — are entirely SYNTHETIC. They are produced
programmatically by the simulation code in `src/streaming_sim/` and by
`scripts/bootstrap_reference_data.py`.

This data does not originate from, describe, or represent any real company,
facility, brand, product, process, or individual. Any resemblance to real
entities is coincidental. The data is provided solely to demonstrate the
solution and carries no warranty of accuracy or fitness for any purpose.
